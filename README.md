# DPI Guard — Android DPI Bypass App (РФ / ТСПУ)

Android-приложение на Kotlin для локального обхода DPI без root-прав через `VpnService`, нативный `hev-socks5-tunnel` (TUN -> SOCKS5 TCP+UDP) и встроенный прокси с автоподбором стратегий под ТСПУ.

## Возможности
- **6 стратегий обхода ТСПУ**: TLS Record Split (двойной и тройной), сплит по середине SNI, 1-байтовый сплит, микро-чанки по 2 байта, мягкий режим без блокировки QUIC.
- **Автоподбор стратегии (сканер)**: проверяет реальное TLS-рукопожатие до YouTube, видео-CDN и Discord по каждой стратегии и автоматически выбирает рабочую с минимальным пингом.
- **Стабильная работа с видео и в фоне**: раздельный `join()` потоков загрузки/отдачи, оптимизированные буферы без утечек памяти.
